## 빈유신

컴퓨터인공지능학부 학생입니다. 보안, 네트워크, 빅데이터 관리에 관심이 있습니다.

## 관심 분야

| 분야 | 관심을 갖게 된 계기 |
|:---:|---|
| :(fas fa-network-wired): **네트워크** | 컴퓨터네트워크 수업에서 Wireshark로 제 PC의 HTTP, DNS 통신을 직접 열어 봤습니다. 배운 내용이 실제로 이렇게 오간다는 걸 보고 재미를 느꼈습니다. |
| :(fas fa-shield-halved): **보안** | 패킷을 열어 보면서 다른 사람도 내 통신을 이렇게 볼 수 있지 않을까 하는 생각이 들었고, 그걸 어떻게 막는지 궁금해졌습니다. |
| :(fas fa-database): **빅데이터 관리** | 앱을 만들면서 데이터베이스를 처음 써 봤고, SQLD를 준비하면서 데이터를 정리하고 관리하는 쪽에 관심이 생겼습니다. |

## 써 본 기술

- Wireshark: 컴퓨터네트워크 수업에서 HTTP, DNS 패킷 확인
- Python: 알고리즘 공부할 때 직접 구현해 보면서 사용
- AI 코딩 도구(Claude): [InstaClone 앱]({{< relref "/posts/instaclone" >}})과 [이 사이트]({{< relref "/posts/portfolio-site" >}})를 만들 때 사용
- Git, GitHub Actions: 이 사이트를 push하면 자동으로 배포되게 구성

## 앞으로 할 것

SQLD 자격증을 공부해서 한 번 응시했는데, 데이터베이스나 SQL을 다루는 수업을 아직 듣지 못한 상태라 거의 비전공자 수준에서 시험을 봤고 결과는 불합격이었습니다.
이번 겨울방학에 다시 볼 계획이고, 이번에는 1과목(데이터 모델링)과 2과목(SQL) 개념부터 정리한 다음 기출문제를 풀어 볼 생각입니다.

보안은 관심은 많지만 아직 실력은 많이 부족합니다. 드림핵 같은 워게임의 입문 문제부터 풀면서 기초를 차근차근 쌓아 갈 생각입니다.
